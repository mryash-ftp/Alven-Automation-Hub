🚀 Alven X - Arduino Master Automation V1
Alven X ek powerful Python-based GUI tool hai jo Arduino developers ke liye repetitive coding tasks ko automate karta hai. Yeh tool seconds mein complex LED patterns aur pinMode configurations generate kar sakta hai.

## ✨ Features

Smart Pattern Generation: Ek click mein 1-10 ya 1,3,5 jaise patterns ke liye digitalWrite code generate karein.

Reverse Mode: Kisi bhi sequence ko ek click mein ulta (Reverse) karein.

Auto Setup: Range select karke pure void setup() ka code auto-generate karein.

Modern UI: Futuristic "Glassmorphic" dark theme ke saath user-friendly interface.

One-Click Copy: Generated code ko direct clipboard par copy karein aur Arduino IDE mein paste karein.

Lightweight & Fast: Bina kisi lag ke turant code output deta hai.

🛠️ Tech Stack
Language: Python 3.12+

GUI Library: CustomTkinter (Modern UI)

Utilities: Pyperclip (Clipboard Management)

## 📥 Installation
Repository Clone karein:

1. Bash :
```
git clone https://github.com/pradeep-alven-dev/Alven-X-Arduino-Automation.git
cd Alven-X-Arduino-Automation
```
2. Dependencies Install :
```
pip install customtkinter pyperclip
```
3. Run :
```
python main.py
````

## 🚀 How To Use
Pin Range: Apne connected pins ki range daalein (e.g., 0 to 13).

Pattern: * Single pin ke liye sirf number likhein (e.g., 5).

Sequence ke liye dash use karein (e.g., 1-10).

Specific pins ke liye comma use karein (e.g., 2,4,6).

Action: Generate Pattern ya Reverse Mode par click karein.

Copy: Code copy karein aur apne Arduino sketch mein paste karein!
